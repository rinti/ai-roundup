# AI Roundup

Daily summaries of AI discussions, news, and releases from the coding/agentic AI corner of Twitter.

A new dispatch lands each morning, compiled by an unattended Claude Code agent following [`TASK.md`](./TASK.md).

**Read the archive: [ai-roundup.rinti.se](https://ai-roundup.rinti.se/)**

Source roundups live in [`roundups/`](./roundups) as dated markdown files. The site is built from those files by [`build.js`](./build.js) and deployed via GitHub Pages on every push.
