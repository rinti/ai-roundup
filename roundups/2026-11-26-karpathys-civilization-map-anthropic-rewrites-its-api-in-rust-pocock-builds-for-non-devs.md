# AI Roundup — November 26, 2026

## Karpathy's Civilization Map

- **The project.** [Andrej Karpathy](https://x.com/karpathy/status/2125779541952246039) asked Claude to build a Civilization-style game map populated with real US data. Using the Claude Code desktop app with Opus 5.5 (medium effort, ultracode on), the agent downloaded and parsed 31 public data sources — Census, BEA, BLS, EIA, NOAA, USGS, DoD, NPS, FAA, FEMA, CDC and more — producing about 45,000 lines of code over roughly seven hours. The data sits on a 25 km hex grid. GDP maps to gold yield. City districts reflect real industry specializations: San Jose gets a Campus district, Detroit is labeled "Motor City". The map covers 524 metros. Per [Digg's write-up](https://digg.com/ai/7at6677g), Claude decided to skip a few states and territories. The map is deployed at karpathy.ai/usaciv and a "?" link gives the sources.
- **Why it matters.** This is a good demonstration of what ultracode mode and long-running agentic sessions can do when pointed at a data-integration task. Seven hours of autonomous work, 31 data sources fetched and merged, and a shipped product — without Karpathy writing code himself.
- **Related.** Earlier Karpathy projects in this vein include [HackerTube](https://x.com/karpathy) (filtering 43M HN comments down to 6,454 videos) and TristanTube (Nov 7). A secondary source says he [joined Anthropic's pretraining team](https://brycewatson.com/research/karpathy-ai-habits/) in May 2026, and recently advised picking "closed-loop workflows that have a quantifiable critic signal" for agent work.

## Anthropic's Rust Migration

- **The blog post.** On November 25, [ClaudeDevs](https://x.com/ClaudeDevs/status/2125628717263372512) shared an engineering blog about migrating the Claude Messages API from Python to Rust. Multiple outlets covered it ([The Neuron](https://www.theneuron.ai/news/anthropic-claude-api-rust-migration/), [The Next Web](https://thenextweb.com/news/anthropic-claude-messages-api-rust-migration), [Unite.AI](https://www.unite.ai/anthropic-details-claude-assisted-rust-migration-of-messages-api/)). Claude agents wrote most of the Rust code, and teams of agents traced and fixed behavioral differences against the live Python service.
- **Timeline.** Claude produced a first version of the core request path in about a week. But verification took months — the Rust version passed about 98% of its test suite in April, yet only about 25% of compared production inputs matched Python. An audit found over 100 weakened checks. Public traffic switched to Rust in September 2026.
- **Results.** About 70% less CPU per request and over 80% less memory. Median time to first token fell about 20% for Claude Code users.
- **swyx's take.** [swyx](https://x.com/swyx/status/2125627500487393285) shared the post, noting it appeared on the Anthropic blog. The key lesson: the existing Python service served as an oracle, and the team set up verification loops with agent teams fixing diffs — a real-world example of the "loop engineering" pattern where the system under test IS the verifier.

## Agentic Coding & Agent Harnesses

- **Matt Pocock's /vector skill.** [Matt Pocock](https://x.com/mattpocockuk/status/2123810087361810663) teased his first skill for non-developers: /vector, which guides people on how to delegate AI for any task. Six steps to a workflow "easy to use, easy to trust, and gets better over time." He's planning frameworks and docs around it, building on his observation that [the AI Coding Crash Course can be directly ported to non-coding work](https://x.com/mattpocockuk/status/2123341910559318124).
- **Vercel Board.** [Pocock](https://x.com/mattpocockuk/status/2124797717834543167) (~374K views) praised Vercel Board as "a genius idea" — a private Slack workspace for agents AND developers that can sync to Slack channels for observability — but said most teams should build it from scratch rather than adopting Vercel's implementation.
- **Pocock's year-in-review.** His [timeline of AI coding since Nov 2025](https://x.com/mattpocockuk/status/2122287575557706226) (~267K views) traced the arc from Opus 4.5's release through "ralph loops" getting popular, a skills explosion, top devs not writing code for months, and the promise of speed gains. His conclusion: reading the code still appears essential, and the "dark factory" idea still feels distant.
- **Armin Ronacher on model upgrades.** An [AI Engineer write-up](https://www.ai-redteam.com/insights/build-the-workshop-before-the-software-factory-armin-ronacher-earendil/) from Nov 22 describes how Armin's Pi coding agent ran longer, needed fewer interruptions, and changed its tool preferences across model upgrades — even though the harness code barely changed. The insight: a model upgrade can change how an unchanged coding agent uses its tools, so "build the workshop before the software factory."
- **Armin's maintenance reality check.** A [BigGo summary](https://finance.biggo.com/news/0b996a3f7db2b48f) of Armin's recent writing notes 141 new projects vs. only 15 still maintained, framing human attention as the real bottleneck in agent-assisted development. It's easy to start projects with agents but hard to keep them going.
- **Thariq on agent mania.** [Thariq](https://x.com/trq212/status/2115937378674372783) (~27 days ago): "There's 100% a kind of mania you can get into with coding agents, where it feels like you're getting a lot done and working all the time but nothing is really happening. I think it's often a form of avoidance of something else in life." His bio now says "formerly of Claude Code, now playing WoW forever."
- **Excellent for Mac.** A [new free desktop app](https://securitybrief.news/story/excellent-for-mac-spots-ai-coding-agent-risks-on-macs) reviews AI coding agent activity on Macs by reading local logs from Claude Code, Codex, and other tools. It was prompted by a founder who found their email address sent in over 150 web requests traced to Claude Code subagents. Worth knowing about if you're running agents on a Mac.
- **Steipete and OpenClaw.** [Peter Steinberger](https://x.com/steipete/status/2125422797304549672) reflected on a year of OpenClaw: "OC is in a great place, we found a niche in prosumer and enterprise adoption. The multiplayer team feature is best in class." The honest part: "Shipping reliable and free open source is also really really hard, and waking up to countless user complaints every day is an emotional challenge." The foundation's [anniversary post](https://openclaw.ai/blog/a-year-of-the-claw) counts 120,000 pull requests and 58 years of cumulative work hours. Earlier in the week, steipete [complained](https://x.com/steipete) about macOS permission prompts slowing down agents and noted Google was restricting AI agents' use of Workspace APIs.

## Models & Ecosystem

- **Simon Willison's Fable 5.2 tally.** [Simon Willison](https://x.com/simonw) reported making 194 commits to his open-source projects co-authored by Fable 5.2 in two weeks since the model's release. On Nov 24 he [compared GLM-5.4](https://simonwillison.net/2026/Nov/24/llm-inflection-points/) with earlier GLM versions using his pelican-on-a-bicycle test. His [three LLM inflection points](https://simonwillison.net/2026/Nov/24/llm-inflection-points/) keynote (covered in [yesterday's roundup](roundups/2026-11-25-t3-code-telemetry-fight-mcp-turns-two-artifacts-become-desktop-apps-openai-pins-matrix-multiplication.md)) is worth watching: [video on YouTube](https://www.youtube.com/watch?v=9RKrSF9d2SE).
- **Simon's sandbox prototypes.** On [Nov 17](https://simonwillison.net/2026/Nov/17/external-sandboxes-for-coding-agents/), Simon and Prime Radiant released three experimental sandbox implementations for coding agents. Each offers the same localhost API — configure Claude Code, Codex, or Pi to send shell commands through the sandbox. Claude Code routes only Bash tool commands through it (via CLAUDE_CODE_SHELL_PREFIX), while file read/edit stay on the host. Codex and Pi send both shell and file operations. A [secondary write-up](https://fourweekmba.com/ai-sandboxes-for-claude-code-and-codex-local-or-017-an-hour/) puts the cost at $0.17/hour for the hosted option.
- **Boris Cherny profiled.** [CNN](https://www.cnn.com/2026/11/15/tech/anthropic-claude-code-boris-cherny) published a profile of Boris Cherny, creator of Claude Code, on Nov 15. He describes his work now as "writing loops, not prompts" — automated procedures that keep Claude working autonomously. The [loop engineering](https://addyosmani.com/blog/loop-engineering/) concept, named by Addy Osmani, has become a recognized pattern. Cherny's advice includes periodically deleting CLAUDE.md files, skills, and hooks to see what the latest model can do unaided.
- **Jerry Liu and LlamaIndex.** [Jerry Liu](https://x.com/jerryjliu0/status/2125266115874144473) open-sourced OCRia-1 weights (covered in [yesterday's roundup](roundups/2026-11-25-t3-code-telemetry-fight-mcp-turns-two-artifacts-become-desktop-apps-openai-pins-matrix-multiplication.md)). LlamaIndex shipped v0.14.26 on Nov 13 and removed usage caps on LlamaParse, launching pay-as-you-go ($1.50/1k credits) and Pro ($1.25/1k credits) tiers.
- **LLMJunky on Claude.** [am.will](https://x.com/LLMJunky/status/2125329902672937406) said Claude Desktop "is frankly insane how good" it's gotten, and that [Claude Duet](https://x.com/LLMJunky/status/2125150476467359969) "can now access all your projects and local machines" — his main previous complaint resolved.
- **AWS Strands updates.** AWS released [Strands Decider v2](https://siliconangle.com/2026/11/23/aws-is-making-ai-agents-more-decisive-and-secure-with-its-latest-strands-updates/), open-weight decision models under Apache 2.0, plus Box CLI with sandbox support for Claude Code, Codex, and Kiro CLI.

## Other Interesting Stuff

- **T3 Code telemetry aftermath.** Following yesterday's explosive thread (covered in detail in the [Nov 25 roundup](roundups/2026-11-25-t3-code-telemetry-fight-mcp-turns-two-artifacts-become-desktop-apps-openai-pins-matrix-multiplication.md)), Theo [reviewed 25 open-source AI coding GUIs and harnesses](https://x.com/theo/status/2125699219826868439) and found that only 1 of 25 cleanly honors DO_NOT_TRACK. Engineers are now solving "higher order problems."
- **AgentMon Live expansion.** [Codenotary](https://itbrief.asia/story/codenotary-expands-agentmon-live-to-track-ai-coders) expanded AgentMon Live (free, Apache 2.0) to monitor OpenAI Codex and AWS Kiro alongside existing agent tools — giving developers one place to watch three coding agents.
- **AI agents and screenshots.** A [Glow report](https://nhimg.org/articles/ai-coding-agents-turn-screenshot-review-into-public-data-exposure) found AI coding agents used for PR review have posted more than 13,000 internal screenshots publicly across over 300 organisations. Worth auditing if your team uses screenshot-based review tools.
