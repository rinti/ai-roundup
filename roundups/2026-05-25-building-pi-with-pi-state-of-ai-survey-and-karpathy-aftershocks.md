# AI Roundup — May 25, 2026

## Agentic Coding & Agent Harnesses

**Armin Ronacher publishes "Building Pi With Pi."** A long-form blog post dropped May 24 reflecting on what happens when you use a coding agent to build itself. The most interesting insight: issue trackers change when agents consume them — issue descriptions stop being just human-to-human messages and become prompt inputs for agent sessions. Ronacher shares his `/is` (analyze issue) prompt setup, which reads the full GitHub thread, labels and assigns the issue, but explicitly tells the agent *not to trust the analysis in the issue and to derive its own diagnosis from the code*. The post also surfaces a frustration that Simon Willison [quoted the same day](https://simonwillison.net/2026/May/24/armin-ronacher/): *"The most frustrating failure mode right now is that people submit issues that are not in their own voice."* Many issues and PRs are complete slop — in some cases the humans didn't even realize they created them. Ronacher's position: if an LLM helped you understand the problem, fine, leave that as a follow-up comment, but the issue text itself should be something you own. [Blog post](https://lucumr.pocoo.org/2026/5/24/pi-oss/) · [Pragmatic Engineer coverage](https://newsletter.pragmaticengineer.com/p/building-pi-and-what-makes-self-modifying).

**Matt Pocock teases Sandcastle.** A new TypeScript library for orchestrating locally sandboxed coding agents: Docker-isolated, 100% offline, commits made in the sandbox get patched back to the host via git worktrees. Provider-agnostic — ships with built-in support for Docker, Podman, and Vercel — and works with Claude, Codex, or OpenCode. The `sandcastle.run()` function creates a worktree, spins up a container, runs the agent, and merges changes back. Pre-1.0 but actively developed (v0.5.10 shipped May 8). Pocock described it as: *"I couldn't find a great, simple framework for parallelising sandboxed coding agents. So, I built one."* [Announcement](https://x.com/mattpocockuk/status/2039343457282531549) · [GitHub](https://github.com/mattpocock/sandcastle).

**Pocock's skill stack continues evolving.** The `/grill-with-docs` skill is now recommended over the original `/grill-me` for codebases, with `/grill-me` reserved for non-code tasks. Experimental `/diagnose` and `/triage` skills landed. The broader workflow remains Idea → `/write-a-prd` → PRD → `/prd-to-issues` → Kanban Board → `ralph.sh` → Ralph Loop → Manual QA, with Sandcastle now slotting in as the orchestration layer for the Ralph Loop. [Skill changelog](https://x.com/mattpocockuk/status/2049770396858089933) · [Skills repo](https://github.com/mattpocock/skills).

**Jerry Liu: the framework scaffolding era is over.** The LlamaIndex CEO told VentureBeat that agent loops are now capable enough that the indexing layers, query engines, and retrieval pipelines developers once needed are collapsing. The new moat is context quality: *"Whether you use OpenAI Codex or Claude Code doesn't really matter. The thing that they all need is context."* A pivot signal for LlamaIndex itself — less framework, more data quality tooling. [VentureBeat](https://venturebeat.com/infrastructure/the-ai-scaffolding-layer-is-collapsing-llamaindexs-ceo-explains-what-survives) · [AI Market Watch](https://www.ai-market-watch.com/news/llamaindex-ceo-argues-context-quality-is-the-new-moat-as-scaffolding-era-ends-6urf7w).

**Boris Cherny asks "what can we do better?"** The Claude Code creator responded to feedback from [@DavidKPiano](https://x.com/bcherny/status/2053950964126921024), continuing his pattern of soliciting direct user input. His recent Claude Code philosophy in a nutshell: *"AI works better when you give tools and freedom instead of forcing them into rigid, hand-designed workflows — because general learning systems scale better."* The `/simplify` and `/batch` skills he announced earlier continue to gain traction — `/simplify` runs parallel agents for code quality, efficiency tuning, and CLAUDE.md compliance; `/batch` handles repetitive refactors across files using isolated git worktrees. [How Boris uses Claude Code](https://howborisusesclaudecode.com/) · [/simplify + /batch announcement](https://x.com/bcherny/status/2027534984534544489).

## Model & Tool Releases

**Simon Willison ships datasette-agent 0.1a4 and three companion releases.** May 24 was a release day: datasette-agent hit 0.1a4, datasette-fixtures 0.1a0 launched (adds a fixtures test database), and datasette itself reached 1.0a30. Datasette Agent is an extensible AI assistant for Datasette that integrates the LLM library, supports hundreds of tool-calling models (OpenAI, Anthropic, Gemini, open-weight local models), and provides a conversational interface for querying SQLite databases. Willison has expressed excitement about building his own "Claw" — a personal AI assistant built around data imported from different parts of his digital life. Live demo at [agent.datasette.io](https://agent.datasette.io/). [Release notes](https://simonwillison.net/2026/May/24/datasette-agent/) · [Original announcement](https://simonwillison.net/2026/May/21/datasette-agent/).

**Karpathy's Anthropic move still reverberating.** A week after announcing he joined Anthropic's pre-training team (May 19), the story continues to generate discussion. His original post drew nearly 3M views in an hour. He's starting a team focused on using Claude to accelerate pretraining research — a signal that Anthropic believes AI-assisted research, not just raw compute, is the competitive edge. On May 24 a parody video — *"Michael Scott introducing Karpathy like he just signed Wemby in free agency"* — crossed 1.2M views, which says something about how culturally significant AI researcher moves have become. [Karpathy's announcement](https://x.com/karpathy/status/2056753169888334312) · [TechCrunch](https://techcrunch.com/2026/05/19/openai-co-founder-andrej-karpathy-joins-anthropics-pre-training-team/) · [Fortune](https://fortune.com/2026/05/19/who-is-andrej-karpathy-vibe-coding-anthropic-openai-rubiks-cube/).

## Industry, Surveys & Takes

**State of AI 2026 survey results are in.** The Devographics survey (7,258 respondents, ran April 8–May 8) delivered striking numbers:

- **AI-generated code doubled**: from 28% average in 2025 to **56%** in 2026, with the 75%+ segment seeing the highest growth
- **61%** use AI for code generation or refactoring at least a few times per day
- **72%** say AI is an integral part of their workflow
- Claude is the model developers **actually pay for** the most, despite ChatGPT having the edge in overall popularity
- ~60% of respondents spend personal money on AI tools; ~18.5% spend over $50/month
- Over half of respondents watch Theo's videos

The verification bottleneck is real: Sonar's companion survey found 96% of devs don't fully trust AI code, only 48% always verify before committing, and 38% say reviewing AI code takes *more* effort than reviewing human code. [State of AI 2026 results](https://2026.stateofai.dev/en-US) · [d4b analysis](https://www.d4b.dev/blog/2026-05-23-what-the-state-of-ai-2026-survey-says-about-developer-work) · [Sonar report](https://www.sonarsource.com/blog/state-of-code-developer-survey-report-the-current-reality-of-ai-coding).

**swyx's "Agentic Nation" keynote at AI Engineer Singapore.** swyx gave the closing keynote at the first AI Engineer Singapore (May 15–17), titled "The Agentic Nation." He admitted he *"burned some bridges but said what I felt."* The conference — organized by local group 65Labs and backed by OpenAI, Google DeepMind, Cursor, Vercel, and Z.ai — marks AI Engineer's expansion into Asia. swyx's broader thesis for 2026: *"2025 was the year of coding agents; 2026 is coding agents breaking containment to do everything else."* [Talk page](https://www.swyx.io/aie-singapore-the-agentic-nation) · [Conference](https://www.ai.engineer/singapore).

**Peter Steinberger at OMR Festival.** Steinberger, who joined OpenAI in February after the OpenClaw viral moment, is speaking at OMR Festival in San Francisco this month on how agentic engineering changes software development. His line: agentic engineering moved from *"this is crap"* to *"this is good"* around May 2025 with Sonnet 4.0, and hit another leap to *"this is amazing"* with gpt-5-codex. OpenClaw has moved to an independent foundation. [steipete.me](https://steipete.me/) · [OpenClaw post](https://steipete.me/posts/2026/openclaw).

**The "vibe slop" crisis gets mainstream coverage.** Ronacher and Mario Zechner's warnings about low-quality AI-generated code have been picked up broadly. Ronacher identifies two root causes: **automation bias** (trusting machine output simply because a machine produced it) and **review fatigue** (developers stop reading carefully when drowning in AI-generated PRs). This is the backdrop for his "Building Pi With Pi" post — not anti-AI, but insisting on structural quality when agents generate the code. [Coverage](https://medium.com/newsarticulated/the-ai-superstars-who-say-a-vibe-slop-crisis-is-coming-and-what-it-means-for-software-s-future-f276c4d875b2).
